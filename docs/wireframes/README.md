## Fluxul de navigare

1. Utilizatorul nou porneste de la Inregistrare, iar cel care are deja cont, de la Autentificare. Intre cele doua ecrane exista legaturi.
2. Dupa autentificare ajunge pe Pagina principala, cu listele lui.
3. De acolo deschide o lista, unde adauga sarcini si invita alti utilizatori.
4. Din bara de sus poate merge oricand la Buget, Rezervari sau Statistici.
5. Din meniul "Cont" se poate deconecta si ajunge inapoi la Autentificare.

Pe telefon, bara de sus devine un meniu, iar cardurile se aseaza unul sub altul.
